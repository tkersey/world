# Frozen v1 comparison tooling

The host adapter here is from World 4.1.2 commit
`a55154eb43d19cba83c0bf1869cfd38704905ff1`. It is used only to compare BPI1
lifting and matched economy workloads with the independently downloaded,
identity-checked Boundary 1.8.2 kernel. It is not exported or packaged in the
World 5 runtime. Historical conformance records remain unchanged under
`conformance/`; their Boundary 1.7.0 identity is distinct from the 1.8.2 kernel.
